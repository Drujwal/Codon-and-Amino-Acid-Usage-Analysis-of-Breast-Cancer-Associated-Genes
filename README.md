# Codon and Amino Acid Usage Analysis of Breast Cancer-Associated Genes

This repository contains the scripts and sequence files used for codon usage bias, amino acid usage, and protein physicochemical analysis of breast cancer-associated genes.

## Files

- **`starX.py`** – Python script used for sequence cleaning, including removal of unwanted `*` and `X` characters.
- **`fasta1.pl`** – Perl script used for processing and extracting selected FASTA sequences.
- **`initiated.pl`** – Perl script used for processing FASTA files and organizing sequence identifiers.
- **`protein.py`** – Python/Biopython script used to calculate protein length, molecular weight, and theoretical isoelectric point (pI).
- **FASTA file** – Input nucleotide sequences of the breast cancer-associated genes.

## Analysis

Codon and amino acid usage analyses were performed using **CodonW** and **DAMBE**. Python/Biopython and Perl scripts were used for sequence processing and protein property calculations.
